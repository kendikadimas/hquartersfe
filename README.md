# HQ Redesign — Enterprise Workspace Web Design

A modern, high-performance web design application built for **HQ Redesign**.

## 🚀 Tech Stack

- **React 19** (`react`, `react-dom`)
- **Vite 6**
- **Tailwind CSS v4**
- **Lucide Icons** (`lucide-react`)
- **Framer Motion** (`framer-motion`)

## 🛠️ Getting Started

### Installation

```bash
npm install
```

### Running Locally

```bash
npm run dev
```

### Production Build

```bash
npm run build
```
